# Telegram Comment Bot

Автоматизатор комментариев для Telegram-каналов и групп. Мониторит новые публикации, отправляет заранее подготовленные шаблоны, поддерживает расписание, многоуровневую систему прав и автоматическое логирование.

## Возможности

- **Авто-комментинг** под новые/пересланные посты
- **Ротация шаблонов** с поддержкой `Faker`-переменных (`{{name}}`, `{{phone}}`, `{{address}}`)
- **Планирование** комментариев на конкретную дату
- **5 уровней прав**: `BASE` → `MODER` → `ADMIN` → `DEV` → `LOGGER`
- **Банворды** с авто-реакцией и ответами
- **Логирование** в админ-чат с автоочисткой записей старше 24ч
- **Веб-интерфейс** для обратной связи и генерации команд планирования

## Технологии

`Python 3.10+` | `Flask 3.0` | `SQLite` | `JSON` | `uWSGI` | `pytest` | `requests`

## Быстрый старт

```bash
git clone https://github.com/твой-ник/commentBot.git
cd commentBot
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Заполни токены и URL
python app.py
```
